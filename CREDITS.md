# Credits

## Sound
- **Sound effects** (select, typing tick, correct, wrong, stage change,
  ending fanfare) are synthesised at runtime with the Web Audio API in
  `src/game/audio/sfx.ts`. No audio files, nothing to license.
- **Music** (`public/assets/stage1.m4a`, `stage2.m4a`, `stage11.mp4`,
  `stage12.mp4`): provided by Amara, who confirmed it is fine to use here.
  Original sources are not recorded.

## Images
All paintings and portraits in `public/assets` (backgrounds, NPC portraits,
player, popup stickers) were provided by Amara, who confirmed it is fine to
use them here. Original sources are not recorded. Four files are named
`Screenshot … unicornio - Google Suche.png` (screenshots of web search
results); that is fine for this project, but get permission or replace them
before publishing the game more widely.
